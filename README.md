## Project Overview
The Smart Retractable Clothesline is an automation system designed to protect laundry from unpredictable weather conditions while reducing the need for manual supervision. This project aims to provide a more convenient and efficient solution through the integration of sensors, electronics and mechanical components such as rain sensors, Light Dependent Resistor (LDR), DC motor, through processing with a microcontroller. 

## Aims
- Manual Control
- High Reliability
- Easy-to-ship Design
- Easy-to-build Design

## Project Scope
- Mechanical Design & Modelling
- Microcontroller & Hardware Integration
- Actuation Mechanism
- IoT Implementation
